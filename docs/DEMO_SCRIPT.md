# DEMO_SCRIPT

## 1. 开场

“这是内镜智训Agent，一个面向消化道内镜医师培训的智能辅导平台。它不是诊断系统，而是训练、解释、复核和审计闭环。”

## 2. 首页总览

先展示“平台真实性与演示路径”：后端 API、真实公开样例、医师画像回灌、报告知识库、Provider、模型准入和审计日志都会显示状态。强调系统会主动标注 `provider`、`rule`、`fallback`，不会把规则草案伪装成真实模型推理。

再展示今日训练、能力雷达、薄弱标签、推荐题型、当前模型和安全提示。强调模型能力分是训练准入状态，不是临床评测结论。

## 3. 训练中心

进入 `/training`，说明三栏结构：

- 左侧：合成内镜教学图、病例摘要、题源标签。
- 中间：题目、选项、提交。
- 右侧：智能辅导 Agent、查看依据、错因分析入口。

点击“提示一下”：Agent 先追问依据，不泄露答案。

选择一个错误答案并提交：展示得分、错因标签和解释。

## 4. 错因分析

进入 `/feedback`，展示用户答案、参考答案、error_tags、atomic facts 表格和下一题推荐。重点讲“系统解释错在哪里，而不是只给分”。

## 5. 错误前提训练

进入 `/false-premise`，展示“图中是否一定有息肉”“是否能确定感染”等题。强调 Agent 能识别题干诱导和证据不足。

## 6. 报告草稿

进入 `/report`，输入“胃窦黏膜充血，可见散在糜烂”。生成结构化所见、草稿印象、复核点和不确定性说明。指出医生审核标识。

## 7. 科普卡片

进入 `/card`，生成患者友好解释。强调免责声明和“不替代医患沟通”。

## 8. Skills / 模型 / 审计

在 `/skills` 运行 `false_premise_guard` 或 `atomic_feedback`。在 `/models` 展示 mock 模型库和风险标签。最后进入 `/audit` 展示关键事件已记录。

## 结束语

“第一版已经跑通核心训练闭环。后续可以接真实 GI-VQA 数据集、VLM provider、课程管理和真实评测流水线，但当前演示严格保持教学和医生审核前辅助边界。”
