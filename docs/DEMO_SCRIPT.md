# DEMO_SCRIPT

## 1. 开场

“这是内镜智训Agent，一个面向消化道内镜医师培训的智能辅导平台。它不是诊断系统，而是训练、解释、复核和审计闭环。”

## 2. 首页总览

先展示“平台真实性与演示路径”：后端 API、真实公开样例、医师画像回灌、报告知识库、Provider、模型准入和审计日志都会显示状态。强调系统会主动标注 `provider`、`rule`、`fallback`，不会把规则草案伪装成真实模型推理。

再展示今日训练、能力雷达、薄弱标签、推荐题型、当前模型和安全提示。强调模型能力分是训练准入状态，不是临床评测结论。

## 3. 训练中心

进入 `/training`，说明三栏结构：

- 左侧：真实公开内镜样例或教学图、病例摘要、题源标签。
- 中间：题目、选项、提交。
- 右侧：智能辅导 Agent、证据、医生 vs 公开标注/Provider 基准对照。

点击“提示一下”：Agent 先追问依据，不泄露答案。

选择一个错误答案并提交：展示得分、错因标签和解释。

进入 `/training?view=challenge`：强调比拼模式先独立作答，提交前证据页和公开标注基准会锁住；提交后才显示医生答案、公开标注/Provider 基准和回合比分。若本回合未调用独立模型，页面会明确标注，不伪装实时模型比赛。

## 4. 错因分析

进入 `/feedback`，展示用户答案、参考答案、error_tags、atomic facts 表格和下一题推荐。重点讲“系统解释错在哪里，而不是只给分”。

## 5. 错误前提训练

进入 `/false-premise`，先让林知远医师独立判断“题干假设是否成立”。提交前页面只给原则提示，不亮答案；提交后解锁得分、证据不足事实、原子证据和下一步复盘建议。强调这个模块既服务医师训练，也服务模型准入中的安全边界测试。

## 6. 报告中心

进入 `/report`，先展示首屏状态带：数据来源、Provider、报告模板。选择公开图像或上传图片，说明公开 VQA 标注只进入“图像来源台账”，不会伪装成医生报告结论。

输入或保留医生所见文本，生成结构化所见、草稿印象、复核点、不确定性说明、证据台账和幻觉审查。指出医生审核标识。

切到 `/report?tab=judge`，演示把“本图明确证明胃癌”这类越界报告改写成带不确定性和复核要求的版本，并回灌医师画像。

## 7. 科普卡片

进入 `/card`，生成患者友好解释。强调免责声明和“不替代医患沟通”。

## 8. Skills / 模型 / 审计

在 `/skills` 选择当前题运行 `false_premise_guard` 或 `atomic_feedback`。页面展示运行摘要、医生复核状态和跳转入口；完整 JSON 只在开发细节折叠项里。

在 `/models` 展示模型接入测试和用户自带 API/key 的一次性准入探测。只有真实 Provider 调用成功才会显示 `provider_called=true`。最后进入 `/audit` 展示关键事件已记录。

## 结束语

“v2.0 已经跑通医师训练、报告训练、错误前提安全、受控 Skills、模型准入和审计闭环。后续可以继续扩展多医师数据库、课程管理和完整评测流水线，但当前演示严格保持教学和医生审核前辅助边界。”
