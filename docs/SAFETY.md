# SAFETY

## 不可违反规则

1. 不替代医生诊断。
2. 不输出最终临床结论。
3. 不给真实患者治疗建议。
4. 不处理真实患者身份信息。
5. 不写真实密钥、服务器信息、Webhook 或 token。
6. 报告草稿和科普卡片必须要求医生审核。
7. 模型能力看板必须标注 mock/预留。

## 当前实现

- 全局安全提示：`仅供教学训练或医生审核前辅助，不作为独立诊断依据。`
- `SafetyService` 检查高风险词，如“确诊”“立即手术”“直接开药”等。
- 报告草稿会对姓名、身份证、住院号、就诊卡号、电话等敏感标记做演示级脱敏后再回显。
- `ReportService` 和 `PatientEducationAgent` 输出 `doctor_review_required=true`。
- `SkillRegistry` 将 high risk skill 自动标记为医生审核。
- `AuditService` 记录题目查看、答题提交、辅导回复、报告草稿、科普卡片草稿、科普卡片审核、skill 调用和模型选择。

## Mock 数据策略

- 使用合成教学图像，不使用真实患者图。
- 题库文本为教学样例，不包含姓名、身份证、住院号等。
- 模型分数只用于 UI 和接口演示。
