# 内镜观察教学资料（项目许可的教学样例）

## 食管黏膜观察

食管检查先记录解剖部位、黏膜连续性、充血或糜烂等可见形态。单帧图像只能支持观察性描述，不能替代病理、完整检查或临床诊断。

## 胃黏膜观察

胃部训练应按部位描述黏膜颜色、皱襞、表面形态和是否存在局灶改变。遇到信息不足时应写明需要结合完整检查和医生复核，而不是推导确定性结论。

## 结直肠复盘

结直肠练习先确认病灶所在肠段，再描述边界、表面和周围黏膜。选择题应回到题干证据逐项排除；开放题应将事实和不确定性分开表达。

## 复习与安全边界

错题复盘以本次可见证据、错误标签和后续复习时间为核心。系统输出仅用于教学研修或医生复核前辅助，不作为独立诊断依据。
