# 简历项目经历｜大模型算法方向

## 项目名称

**内镜多模态模型后训练、评测与部署优化系统**

技术栈：Python、PyTorch、Transformers、PEFT、BitsAndBytes、**VLM Evaluation、QLoRA、DPO、Post-Training、INT8/NF4 Quantization、Prompt Ablation、Inference Benchmark**

## 项目简介

面向公开内镜图文任务构建多模态模型算法实验体系，覆盖数据集版本化、统一推理协议、多模型选型、事实级评测、QLoRA/DPO 后训练、INT8/NF4 部署优化、结构化输出消融与 Bad Case 分析；在双服务器 GPU 环境完成 3 个 VLM、7 组主实验、21 条逐例结果及 5-seed DPO 复验，并将模型能力接入医生研修 Agent 展示。

## 项目具体内容

- 针对医学多模态实验容易发生训练/测试污染、仅展示单次截图的问题，为保证结果可复现，构建 **版本化数据与评测协议**，将 10 张公开教学图像固定划分为 train/dev/test=4/3/3，记录样例 ID、数据来源、Prompt、解码参数、环境和逐例输出；完成 **3 个 VLM、7 个 run、21 条逐例结果**，所有结果聚合为 JSON Artifact。

- 针对模型选型只比较参数量、无法同时衡量效果与资源的问题，为寻找研修 Agent 的性价比模型，采用同一 Prompt、greedy、batch=1 协议对比 **Qwen2.5-VL-3B、LLaVA-OneVision-0.5B、SmolVLM-256M**；独立 test 上事实准确率分别为 **66.7%/66.7%/33.3%**，其中 LLaVA 以 **0.091s P50、2.00GiB 峰值显存**达到与 Qwen 3B 相同的小样本准确率。

- 针对 BF16 模型单卡显存占用较高、Demo 部署资源受限的问题，为寻找精度—显存—延迟平衡点，对 Qwen2.5-VL-3B 完成 **BF16、NF4 4-bit、LLM.int8 PTQ** 对比；NF4 在该固定 test 上保持 **66.7%** 事实准确率，峰值显存由 **7.47GiB 降至 2.62GiB（-64.96%）**，P50 仅增加 **11.60%**，验证 4-bit 量化更适合单卡演示部署。

- 针对领域数据量小、参数高效微调可能产生训练集假提升的问题，为验证真实泛化而非只看 loss，使用 **NF4 QLoRA（r=8、q/v_proj）** 训练 184.32 万参数，仅占总参数 **0.0491%**，将训练样例 loss 从 1.9071 降至 1.7230；进一步在从未参与训练的 test 上执行 before/after，事实准确率 **66.7%→66.7%**，识别出小数据 QLoRA 未带来泛化提升，避免将训练集收敛误写成效果提升。

- 针对自由文本输出难以被 Agent 工具稳定解析的问题，为提升结构化消费能力，设计 **Structured Prompt / JSON Schema 消融实验**；在事实准确率保持 **66.7%** 的条件下，JSON 有效率由 **0% 提升至 100%**，同时量化 P50 由 0.308s 增至 0.350s（+13.45%），为结构化稳定性与推理开销提供明确选型依据。

- 针对模型容易给出过度确定表达、且后训练可能产生数值异常的问题，构建 4 组 **chosen/rejected 偏好数据**并完成 **cached-reference DPO + NF4 QLoRA** 20-step 训练：冻结 test 安全边界率由 **0% 提升至 100%**、事实准确率保持 66.7%、P50 增加 76.9%；进一步执行 **5-seed 稳定性复验**，首轮 4/5 完成、1 次出现 NaN，保留失败 Artifact 并加入 **NaN/Inf fail-closed 门禁**，同 seed 重试完成，避免将无效 run 静默计为成功。

- 针对整例准确率无法定位复杂问答失败原因的问题，为支持数据迭代，将参考答案拆解为 **Fact-level Rubric**，同时计算 case exact、micro fact accuracy、P50/P95、tokens/s、吞吐和峰值显存；通过逐例 Bad Case 定位“小肠误判为胃、空间位置遗漏、阴性发现缺失”等领域失配，形成后续难例采样和监督数据构建方向。

- 针对模型文件下载不完整和实验环境漂移导致结果不可复现的问题，为建立模型资产门禁，对新增模型执行 **exact file size + Hugging Face LFS SHA256** 双校验，保存 Python/PyTorch/Transformers/CUDA 环境、完整命令、原始日志和逐例 JSONL；聚合程序自动核对 run 数、summary 数与结果行数，保证 **7/7 runs、21/21 rows** 一致。

- 针对离线算法结果难以体现业务价值的问题，为验证模型能力落地，将模型实验 Artifact 接入 **多模态研修 Agent**，通过可解释检索、Tool Calling、事实评分与 Memory 将 VLM 输出转化为可复盘任务结果，并在评测实验室中展示模型、量化、微调与 Prompt 消融的真实 trade-off。
