# 评测体系与真实结果（v2.1）

## 1. Agent Runtime 回归

Artifact：`artifacts/eval/latest.json`

| 评测内容 | 规模 | 结果 |
|---|---:|---:|
| Golden Cases | 5 | 任务/工具/证据/结构/安全回归通过 |
| Evidence Retrieval | 19 queries | Recall@1/3 = 100%/100% |
| Tool Fault Injection | 3 类 timeout | Recovery = 100% |
| Checkpoint Replay | 1 固定重放链路 | Replay = 100% |
| Safety Probes | 3 | 判定正确 |

延迟只衡量单进程 Python 规则 Runtime，不含 HTTP、模型推理或前端。Golden Case 的 100% 是确定性回归率，不是 VLM 或临床准确率。

## 2. 数据与统一模型协议

- 10 张公开教学图像，冻结 train/dev/test=4/3/3。
- 所有模型使用同一 test、Prompt、greedy decoding 和 batch=1。
- 保存模型/精度/软件/配置、逐例原始输出、Fact hits、延迟和显存。
- test 三张图从未参与 QLoRA/DPO 的训练。

聚合 Artifact：`artifacts/model_eval_v21/aggregate_summary.json`。

## 3. 三模型同协议对比

| 模型 | Fact Accuracy | P50 | Peak GPU |
|---|---:|---:|---:|
| Qwen2.5-VL-3B | 66.7% | 0.308s | 7.47GiB |
| LLaVA-OneVision-0.5B | 66.7% | 0.091s | 2.00GiB |
| SmolVLM-256M | 33.3% | 0.201s | 2.78GiB |

这只是三张固定 test 的模型选型证据，不是权威模型排名；但能说明该任务上参数更大的模型并不必然有更好的效果—资源比。

## 4. 量化部署对比

| Qwen2.5-VL-3B | Fact Accuracy | P50 | Peak GPU | 相比 BF16 |
|---|---:|---:|---:|---:|
| BF16 | 66.7% | 0.308s | 7.47GiB | baseline |
| NF4 | 66.7% | 0.344s | 2.62GiB | 显存 -64.96%，P50 +11.60% |
| INT8 | 66.7% | 0.629s | 4.30GiB | 显存 -42.52%，P50 +104.0% |

该固定 test 上 NF4 的资源 trade-off 明显优于 INT8，适合作品集单卡部署。

## 5. QLoRA 与独立评测

NF4 QLoRA 使用 r=8、alpha=16、q/v_proj，仅训练 184.32 万参数（0.0491%），训练样例 loss 1.9071→1.7230；但 frozen test Fact Accuracy 66.7%→66.7%。因此训练链路成立，但没有观察到泛化提升。

## 6. Structured Prompt 消融

Structured Prompt 将 JSON 有效率 0%→100%，事实准确率保持 66.7%，P50 0.308s→0.350s（+13.45%）。它提升的是工具可解析性，不是视觉识别能力。

## 7. DPO 偏好对齐

Artifact：`artifacts/model_eval_v21/results/dpo_alignment/summary.json`

- 4 对 chosen/rejected，20 step，cached-reference DPO + NF4 QLoRA。
- Loss 0.7043→0.1111；末轮训练偏好胜率 100%。
- Frozen test 完整安全边界率 0%→100%。
- Fact Accuracy 66.7%→66.7%，未观察到专业事实提升。
- P50 1.335s→2.361s（+76.9%）。

因此只将 DPO 表述为“改善安全边界表达”，不写成整体模型能力或临床能力提升。

## 8. DPO 多种子与数值门禁

Artifact：`artifacts/model_eval_v21/dpo_stability_summary.json`、`artifacts/model_eval_v21/dpo_stability_report.md`

- 复用 4 对 train-only preference 与 3 张 frozen test，执行 seed 7/13/29/43/61 五组复验。
- 首轮 4/5 正常完成；1 个 run 出现 NaN 和无效输出，原始 summary、逐例输出、history 与日志均保留。
- 训练脚本新增 `finite_scalar()`，reference log-prob 或 loss 出现 NaN/Inf 时立即 fail-closed，不允许写成 completed。
- 同 seed 门禁重试完成，但异常没有稳定复现；因此只声明“观察并治理一次非有限数”，不声明 DPO 已充分稳定。

## 9. Bad Case

逐例结果能定位：解剖部位迁移错误、空间信息遗漏、阴性事实遗漏、自由文本不可解析、过度确定表达。后续数据迭代应优先增加部位 hard negatives、复合事实监督和拒答/边界偏好对，而不是盲目增加训练 step。
