# v2.2.1 视觉规范与组件库

> 为了保证四模块的视觉一致性和可维护性，统一定义设计规范和可复用组件。

## 设计原则

### 1. 清晰优于炫技
- 医学教育场景优先可读性和功能性
- 避免过度动画和装饰性元素
- 信息密度适中，留白合理

### 2. 一致性
- 同一语义元素使用相同视觉样式
- 交互反馈统一（hover、active、focus）
- 错误、警告、成功状态使用一致的色彩

### 3. 响应式优先
- 移动端优先设计，渐进增强到桌面端
- 触控目标 ≥ 44px
- 避免横向滚动

## 色彩系统

### 主色（Primary）
- **Emerald-600** `#059669` - 主操作、链接、强调
- **Emerald-700** `#047857` - Hover 状态
- **Emerald-50** `#ECFDF5` - 背景淡化

### 中性色（Neutral）
- **Neutral-900** `#171717` - 主要文本
- **Neutral-700** `#404040` - 次要文本
- **Neutral-500** `#737373` - 辅助文本、占位符
- **Neutral-300** `#D4D4D4` - 边框
- **Neutral-100** `#F5F5F5` - 背景淡化
- **Neutral-50** `#FAFAFA` - 页面背景

### 语义色
- **Amber-600** `#D97706` - 警告、待复习
- **Red-600** `#DC2626` - 错误、危险操作
- **Blue-600** `#2563EB` - 信息提示
- **Green-600** `#16A34A` - 成功（避免与主色混淆时使用）

## 排版系统

### 字体
- **正文**：系统默认字体栈
- **代码**：`'Courier New', monospace`

### 字号
- `text-2xl` (24px) - 页面标题
- `text-lg` (18px) - 题干、卡片标题
- `text-base` (16px) - 正文、选项
- `text-sm` (14px) - 辅助信息、标签
- `text-xs` (12px) - 次要标签

### 行高
- 题干、说明文字：`leading-relaxed` (1.625)
- 正文：`leading-normal` (1.5)
- 标题：`leading-tight` (1.25)

---

## 间距系统

基于 4px 基准单位：

- `gap-2` (8px) - 标签、小按钮间距
- `gap-3` (12px) - 表单元素间距
- `gap-4` (16px) - 卡片内元素间距
- `gap-6` (24px) - 区块间距
- `gap-8` (32px) - 模块间距

## 组件规范

### 按钮（Button）

#### 主按钮（Primary）
```tsx
<button className="px-6 py-2 bg-emerald-600 text-white rounded-lg hover:bg-emerald-700 transition-colors disabled:opacity-50">
  开始练习
</button>
```

**使用场景**：主要操作、提交、确认

#### 次要按钮（Secondary）
```tsx
<button className="px-4 py-2 bg-white border border-neutral-300 text-neutral-700 rounded-lg hover:bg-neutral-50 transition-colors">
  取消
</button>
```

**使用场景**：取消、返回、辅助操作

#### 图标按钮
```tsx
<button className="p-2 hover:bg-neutral-100 rounded-lg transition-colors">
  <BookmarkPlus className="w-5 h-5" />
</button>
```

**使用场景**：收藏、更多操作、关闭

### 卡片（Card）

#### 题库卡片
```tsx
<div className="bg-gradient-to-br from-white to-neutral-50 border border-neutral-200 rounded-xl p-5 cursor-pointer hover:shadow-lg hover:-translate-y-0.5 transition-all">
  {/* 内容 */}
</div>
```

#### 统计卡片
```tsx
<div className="bg-white border border-neutral-200 rounded-xl p-6">
  <div className="inline-flex p-2 rounded-lg bg-emerald-50 text-emerald-600 mb-3">
    <Icon className="w-5 h-5" />
  </div>
  <div className="text-2xl font-semibold mb-1">{value}</div>
  <div className="text-sm text-neutral-600">{label}</div>
</div>
```

### 输入框（Input）

#### 文本输入
```tsx
<input
  type="text"
  placeholder="搜索题库/知识点"
  className="w-full px-3 py-2 border border-neutral-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-emerald-500"
/>
```

#### 文本域
```tsx
<textarea
  placeholder="请输入你的答案..."
  className="w-full h-32 p-4 border border-neutral-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-emerald-500"
/>
```

### 选择题选项

#### 单选
```tsx
<label className={`flex items-start gap-3 p-4 border-2 rounded-lg cursor-pointer transition-colors ${
  selected ? 'border-emerald-600 bg-emerald-50' : 'border-neutral-200 hover:border-neutral-300'
}`}>
  <input type="radio" className="mt-1" />
  <span className="flex-1">选项文本</span>
</label>
```

#### 多选
```tsx
<label className={`flex items-start gap-3 p-4 border-2 rounded-lg cursor-pointer transition-colors ${
  selected ? 'border-emerald-600 bg-emerald-50' : 'border-neutral-200 hover:border-neutral-300'
}`}>
  <input type="checkbox" className="mt-1" />
  <span className="flex-1">选项文本</span>
</label>
```

### 标签（Tag）

#### 题型标签
```tsx
<span className="px-2 py-1 bg-emerald-100 text-emerald-700 rounded text-sm">
  单选
</span>
```

#### 状态标签
```tsx
<span className="px-2 py-1 bg-neutral-100 text-neutral-600 rounded text-xs">
  中等难度
</span>
```

### 加载状态

#### Spinner
```tsx
<div className="flex items-center justify-center min-h-[400px]">
  <div className="text-center">
    <div className="animate-spin w-8 h-8 border-4 border-emerald-600 border-t-transparent rounded-full mx-auto mb-3"></div>
    <div className="text-neutral-500">加载中...</div>
  </div>
</div>
```

#### 进度条
```tsx
<div className="w-full bg-neutral-200 rounded-full h-1.5">
  <div
    className="bg-emerald-600 h-1.5 rounded-full transition-all"
    style={{ width: `${progress}%` }}
  />
</div>
```

### 错误提示

#### 行内错误
```tsx
<div className="p-3 bg-amber-50 border border-amber-200 rounded-lg flex items-start gap-2">
  <AlertCircle className="w-5 h-5 text-amber-600 flex-shrink-0 mt-0.5" />
  <span className="text-sm text-amber-800">错误信息</span>
</div>
```

#### 页面级错误
```tsx
<div className="max-w-4xl mx-auto px-4 py-12 text-center">
  <div className="mb-4 text-amber-600">
    <AlertCircle className="w-12 h-12 mx-auto mb-2" />
  </div>
  <p className="text-neutral-600 mb-4">错误描述</p>
  <button className="btn-primary">重试</button>
</div>
```

## 响应式断点

### 移动端（< 640px）
- 单栏布局
- 导航收起为汉堡菜单
- ChatAgent 全屏覆盖
- 触控目标 ≥ 44px

### 平板（640px ~ 1024px）
- 双栏布局（题库卡片 2 列）
- 导航横向展开
- ChatAgent 仍为全屏

### 桌面（≥ 1024px）
- 多栏布局（题库卡片 3-4 列）
- ChatAgent 固定右侧 320px
- Hover 效果启用

---

## 无障碍（Accessibility）

### 颜色对比
- 正文文本对比度 ≥ 4.5:1
- 大号文本对比度 ≥ 3:1
- 避免仅依赖颜色传达信息

### 键盘导航
- 所有交互元素可 Tab 聚焦
- Focus 状态明显（ring-2）
- 支持 Enter/Space 激活

### 屏幕阅读器
- 图片提供 alt 文本
- 表单元素有 label
- 使用语义化 HTML

---

## 动画规范

### 过渡动画
- 使用 `transition-colors` 或 `transition-all`
- 时长：150ms ~ 300ms
- 缓动函数：ease-in-out

### 加载动画
- Spinner 使用 `animate-spin`
- 骨架屏使用 `animate-pulse`

### 交互反馈
- Hover：`hover:shadow-lg hover:-translate-y-0.5`
- 点击：保持简洁，避免过度动画

## 图标使用

统一使用 **Lucide React**：

```tsx
import { BookOpen, CheckCircle2, AlertCircle } from 'lucide-react'

<BookOpen className="w-5 h-5" />        // 常规图标
<CheckCircle2 className="w-6 h-6" />    // 反馈图标
<AlertCircle className="w-12 h-12" />   // 页面级图标
```

## 文案规范

### 语气
- 友好、专业、简洁
- 避免技术术语（如 Run、Receipt、Memory）
- 使用用户场景语言（练习、题库、复习）

### 示例
- ✅ "提交答案"
- ❌ "Submit Response"
- ✅ "加载中..."
- ❌ "Loading data from backend..."
- ✅ "加载题目失败，请检查网络连接"
- ❌ "API request failed with status 500"
