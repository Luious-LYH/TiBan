# v2.2.1 前端 PRD 与页面设计

> 状态：v2.2.1 执行基准文档
> 
> 目标：将当前单页三栏过渡版改造为四模块产品，确保信息架构清晰、可深链、可恢复、可展示。

## 一、产品定位

**内镜刷题 Agent · EndoTutor**

面向消化内镜研修医的智能刷题平台，提供题库练习、实时带教、错题复习和模型评测能力。

## 二、用户角色与核心任务

| 角色 | 核心任务 | 成功标准 |
|---|---|---|
| 研修医 | 选择题库 → 刷题 → 获得讲解 → 复习错题 | 5 秒内决定下一步，刷题过程可随时请教 |
| 题库维护者 | 导入题目 → 预览校验 → 发布 | 导入错误可读，草稿可预览 |
| 模型评测者 | 选择评测集 → 配置 API → 查看结果 | 明确区分未调用/调用中/完成/失败 |

## 三、四模块信息架构

### 3.1 主导航

```
┌─────────────────────────────────────────────────────────────┐
│ EndoTutor    [学习总览] [题库] [刷题工作台] [模型评测]       │
└─────────────────────────────────────────────────────────────┘
```

严格四个主入口，不再增加第五个业务模块。

### 3.2 页面职责矩阵

| 路由 | 用户看到的名称 | 只解决什么问题 | 不能出现 |
|---|---|---|---|
| `/` | 学习总览 | 我今天该做什么、哪些待复习 | 题目选项、提交按钮、全量题目列表 |
| `/banks` | 题库 | 我有哪些题库、如何导入新题 | 直接答题、Agent trace |
| `/practice` | 刷题工作台 | 我现在答哪道题、如何提交 | 题库总目录、原始 JSON |
| `/eval` | 模型评测 | 我选择哪套评测题、结果如何 | 刷题进度、患者数据 |

## 四、页面详细设计

**页面目的**：让用户 5 秒内决定下一步，不直接答题。

```
├──────────────────────────────────────────────────────────────┤

│ [继续上次练习]                [开始到期复习]                   │
├──────────────────────────────────────────────────────────────┤
│ 我的题库                                        [查看全部 →]   │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐         │
│ │ 食管基础 │ │ 胃部观察 │ │ 小肠胶囊 │ │+ 导入题库│         │
│ │ 42题 68% │ │ 38题 51% │ │ 26题 20% │ │          │         │
│ │[开始练习]│ │[开始练习]│ │[开始练习]│ │          │         │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘         │
├──────────────────────────────────────────────────────────────┤
│ 最近练习                                                       │
│ · 胃部观察 - 第 12 题 - 2 小时前                              │
│ · 食管基础 - 第 8 题 - 昨天                                   │
└──────────────────────────────────────────────────────────────┘
```

#### 组件规格

**统计卡片**（4 个）
- 尺寸：固定高度 120px，响应式宽度
- 数据：今日完成/目标、待复习数、本周正确率、连续天数
- 状态：有数据、空数据（首次使用）、加载中、离线
- 交互：仅展示，不可点击

**题库书本卡**
- 尺寸：宽 240px × 高 180px（桌面），移动端全宽
- 必含字段：题库名称、部位标签、题量、完成度进度条、题型标签、最近练习时间
- 操作：点击卡片或"开始练习"跳转 `/practice?bank_id={id}`
- 状态：正常、未发布、空题库
- 视觉：书本式图标、渐变背景、圆角 12px

**快速开始按钮**
- "继续上次练习"：恢复最近一次未完成会话
- "开始到期复习"：从 FSRS 到期队列选题

#### 数据来源

- `GET /api/portfolio/study`：今日任务、待复习、统计、题库卡片、最近记录
- `GET /api/question-banks`：题库列表、进度

#### 状态处理

| 状态 | 展示 |
|---|---|
| 首次使用 | "欢迎！选择一个题库开始你的第一次练习" |
| 加载中 | 骨架屏，不展示占位数字 |
| 空题库 | "暂无题库，点击'导入题库'开始" |
| 离线 | "无法连接后端，请检查服务状态" |

### 4.3 刷题工作台 `/practice?bank_id={id}&session_id={id}`

**页面目的**：一次只完成一个题库/会话，所有注意力放在作答。

#### 桌面布局（≥1024px）

```
┌──────────────────────────────────────────────────────────────┐
│ 食管基础 / 今日练习          3 / 10   [收藏] [退出]          │
├────────────────────────────────┬─────────────────────────────┤
│ 题型：单选    难度：基础        │  智能带教                    │
│                                │  "卡住了吗？我可以给提示"    │
│ Barrett 食管记录时应优先写入…  │  [拆知识点] [给提示]         │
│                                │                              │
│ [图片区域 4:3]                 │  ───────────────────────     │
│                                │  消息滚动区                  │
│ ○ A. 最终诊断结论              │                              │
│ ○ B. 可观察到的黏膜特征        │  你：这道题考什么？          │
│ ○ C. 治疗方案建议              │  助教：这道题主要考察...     │
│ ○ D. 患者预后判断              │                              │
│                                │  ───────────────────────     │
│ [上一题]  [标记]  [提交答案]   │  输入：问问这道题            │
│                                │  [发送] [停止生成]           │
└────────────────────────────────┴─────────────────────────────┘
```

#### 移动端布局（<768px）

主体区域全宽，ChatAgent 变为底部 sheet（点击展开后全屏显示）。

#### 题目渲染规格

**纯文本题**
- 不渲染空图片容器
- 题干最大宽度 720px，行高 1.6

**图文题**
- 图片容器统一 aspect-ratio: 4/3
- object-fit: contain，不裁切不拉伸
- 支持点击放大查看
- 加载状态：骨架屏
- 失败状态："图像暂不可用，你仍可继续答题 [重试]"
- Alt 文本：显示来源和用途

**选项**
- 单选：圆形单选框
- 多选：方形复选框
- 选中状态：边框高亮、背景色浅色
- 触控目标：≥44px

#### 数据来源与状态

- `GET /api/practice/questions?bank_id={id}`：加载题目
- `POST /api/practice/sessions`：创建/恢复会话
- `POST /api/practice/submit`：提交答案
- `POST /api/practice/tutor`：Tutor 请求（SSE 或轮询）

#### 状态处理

| 状态 | 行为 |
|---|---|
| 进入页面 | 根据 session_id 恢复或创建新会话 |
| 刷新页面 | 通过 session_id 恢复当前题和进度 |
| 提交中 | 禁用提交按钮，显示加载状态 |
| 提交失败 | 保留已填答案，显示错误提示和重试 |
| Tutor 超时 | 保留已生成文本，允许重试 |
| 离线 | 题目可继续作答，提交时提示离线 |

#### 安全要求

- API key 只驻留请求生命周期内的后端内存
- 页面刷新即清空，不写数据库、日志、artifact

- 未真实调用不得显示模型得分
- 评测失败明确区分：无 key、认证失败、超时、429、无效 JSON

## 五、组件复用规范

### 5.1 书本式题库卡片

**组件名**：`BankCard`

**Props**：
```typescript
interface BankCardProps {
  bankId: string
  name: string
  bodyPart: string
  totalQuestions: number
  progress: number // 0-100
  questionTypes: string[] // ["单选", "多选"]
  lastPracticeAt?: string
  status: 'normal' | 'draft' | 'empty'
  onClick: (bankId: string) => void
}
```

**视觉规格**：
- 宽 240px × 高 180px（桌面）
- 圆角 12px
- 书本图标 + 渐变背景
- 进度条圆角 999px
- 悬停：轻微上浮 2px，阴影加深

### 5.2 统计卡片

**组件名**：`StatCard`

**Props**：
```typescript
interface StatCardProps {
  icon: React.ReactNode
  label: string
  value: string | number

```

### 5.3 ChatAgent 侧栏

**组件名**：`TutorSidecar`

**Props**：
```typescript
interface TutorSidecarProps {
  questionId: string
  bankId: string
  currentQuestion: Question
  userAnswer?: string | string[]
```

## 八、验收清单

完成以下验收项，v2.2.1 才可标记完成：

- [ ] `/` 是学习总览，不可直接答题；统计、待复习、题库书本卡可读
- [ ] `/banks` 能看到食管/胃/小肠题库及题量/进度/题型，导入校验在此完成
- [ ] 点击题库卡进入 `/practice?bank_id=...`，刷新后会话仍可恢复
- [ ] `/practice` 一次只展示当前题，单选/多选/判断/简答可刷；纯文本和图文均正常
- [ ] 桌面右侧有独立 ChatAgent，移动端是 bottom sheet；提示、追问、讲解、取消、重试和错误态可用
- [ ] 提交前 Tutor 不收到 answer key；提交后能展示逐项解析、知识点和复习动作
- [ ] `/eval` 可选择评测集、配置一次性 API，并明确区分未调用/调用中/完成/失败；未调用不显示得分
- [ ] 普通页面没有 Run/Receipt/Memory/dense score 等开发术语；技术详情仍可追溯
- [ ] `npm run build`、`npm run lint`、后端单测通过；375/768/1280 无横向滚动
- [ ] README、演示脚本只写已经真实存在并可复现的能力
