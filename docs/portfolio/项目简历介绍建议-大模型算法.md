# 项目简历介绍建议：大模型算法方向

## 推荐项目名

**内镜多模态模型评测与 Agent 落地系统**

技术栈：Python、PyTorch/Transformers（以实际实验环境为准）、VLM Evaluation、Fact-level Metrics、FastAPI

## 当前可直接使用的项目描述

> 面向公开内镜图文任务构建版本化评测与应用闭环，将模型输出拆解为可观察事实、证据充分性、安全边界和结构化表达等维度，并通过 Agent 研修 Demo 展示模型能力落地。

- 构建 5 个版本化医生研修病例、19 条原子事实和 3 条安全对抗探针，设计事实级 Precision/Recall/F1、工具选择、证据覆盖、安全边界和结构化输出等指标，保存逐例 JSON/Markdown Artifact，支持自动回归与 Bad Case 定位。
- 将历史硬编码模型分数与模型名称哈希评分下线，改为从真实逐例输出计算图像问答、事实覆盖、边界表达和可解析率；无真实调用时返回“未运行”，避免占位结果进入简历或演示。
- 实现 OpenAI-compatible 多模态模型接入与盲测流程，参考答案不进入 Provider Prompt，模型输出后再执行事实对齐，并记录模型、样本、延迟、调用模式和错误原因。

## GPU 实验后的推荐条目

- 在 RTX 4090/BF16 上部署 Qwen2.5-VL-3B-Instruct，对 7 张公开内镜教学图像执行确定性推理；测得事实级准确率 20.0%、P50/P95 延迟 0.871/1.646s、19.81 tokens/s 和 10.20GiB 峰值显存，并通过逐例事实命中定位“小肠误判为胃、复杂属性遗漏”等领域失配。
- 基于 NF4 双重量化与 LoRA（r=8，q/v_proj）完成 7 例 10-step 训练链路验证，仅训练 184.32 万参数、占总参数 0.0491%；固定训练样例 loss 从 1.9071 降至 1.7230，峰值显存 17.98GiB，持久化 7.05MiB Adapter。由于没有独立验证集，明确不宣称泛化提升。

## 一段式精简版本

> 构建内镜 VLM 可复现评测链路，在 RTX 4090 上对 Qwen2.5-VL-3B 的 7 张公开样例进行事实级拆分评分，测得 20.0% 事实准确率、0.871/1.646s P50/P95 延迟及 10.20GiB 峰值显存，定位通用模型的内镜领域失配；进一步以 NF4+LoRA（r=8、0.0491% 参数可训练）完成 10-step 训练链路与 Adapter 持久化，固定训练样例 loss 下降 9.65%，并严格区分训练集 sanity 与泛化效果。

## 不建议写入

- 未完成的 DPO、GRPO、RLHF 或蒸馏。
- 没有 checkpoint 和独立测试集支撑的“微调提升 X%”。
- Agent 固定回归 100% 作为 VLM 准确率。
- 临床诊断准确率、医生效率和真实用户满意度。
