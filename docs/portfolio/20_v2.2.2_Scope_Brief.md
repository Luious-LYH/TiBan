## 4. API 事实源（统一类型契约）

### Question 类型
```typescript
type Question = {
  id: string
  bank_id: string
  title: string
  question: string
  question_type: 'single_choice' | 'multiple_choice' | 'true_false' | 'short_answer'
  options?: { id: string; text: string }[]
  answer: string | string[]
  explanation: string
  knowledge_points: string[]
  body_part: string
  modality: 'text' | 'image_text' | 'image'
  image_url?: string
  image_alt?: string
  difficulty?: 'easy' | 'medium' | 'hard'
  tags: string[]
}
```

### 关键接口
- `GET /api/question-banks` → 真实题库摘要（删除前端硬编码）
- `GET /api/practice/questions?bank_id=...` → 按题库过滤题目
- `POST /api/practice/submit` → 统一提交和反馈
- `POST /api/practice/tutor` → 真实带教服务
- `POST /api/question-banks/import/validate` → 真实校验结果
- `GET /api/models/evaluation` → 真实 Artifact
