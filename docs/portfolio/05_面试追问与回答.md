# 面试追问与回答

## 这真的是 Agent，还是工作流？

它是受控 Agentic Workflow，而不是完全自治 Agent。系统具备目标、状态、工具、观察、验证、记忆和运行 Trace，但工具集合和医疗边界固定。这样可以控制风险，并对每一步做回归评测。

## 为什么不用 LangGraph？

当前只有五个稳定节点，自研状态图接口更小，也能展示我对 Agent Runtime 的理解。若扩展为动态长任务、多 Agent 或人工中断恢复，会迁移到 LangGraph/AgentScope，并增加 checkpoint 与状态持久化。

## 为什么固定 Golden Case 能达到 100%？

这是回归测试，Gold Answer 本来就应通过。它验证工具顺序、结构、证据覆盖和安全策略没有退化，不是模型泛化准确率。真实模型能力放在独立 VLM Benchmark 中评估。

## Fact Grader 有什么局限？

当前采用受控同义表达匹配，适合 Demo 和确定性回归，但对复杂否定、指代和语义等价仍有限。后续会增加 embedding/LLM-as-Judge，并用人工复核子集校准一致性。

## 为什么聊天不再提升能力分？

聊天次数不能代表能力提升。只有带事实证据的有效作答或报告修改才应改变画像；普通追问只形成交互记忆。

## 如何保证模型失败时还能演示？

Provider 调用有明确超时和失败状态；失败后进入 Rule/Fallback，UI 显示来源。核心研修闭环不依赖外部网络，但不会把规则输出包装成模型结果。

## 为什么不用真实患者数据？

作品集目标是展示 Agent/评测工程，而不是临床上线。公开教学样例足够验证技术链路，同时避免患者隐私和不可控临床结论。
