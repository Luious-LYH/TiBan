# 从这里开始：作品集阅读与演示地图

本目录服务两类读者：需要快速上手项目的维护者，以及会追问实现和实验边界的技术面试官。

## 一句话定位

**内镜智训 Agent** 是一个面向消化内镜研修的多模态教学 Demo。它以传统刷题业务为外壳：今日计划、病例题库、作答、错题、收藏和间隔复习；以受控 Agent 为核心：对公开教学图像作答执行证据检索、事实评分和安全核验，并把可解释结果写入可重置学习状态。

项目不提供自主临床诊断，所有医学输出均为教学或医生复核前辅助。

## 先看这条产品主链

```text
/study 研修中心
  今日自适应计划 / 题库 / 错题 / 收藏 / 复习
       ↓ 选择病例
/workbench?case=... Agent 工作台
  Plan → Act → [Recovery] → Observe → Verify → Memory
       ↓ 作答后写入运行态学习记录
/study 研修中心
  进度、最佳分、错题/消错、复习队列、下一题推荐
       ↓ 技术追问
/lab 评测实验室
  Agent 固定回归  ↔  VLM / 量化 / QLoRA / DPO Artifact
```

现场默认从 **`/study`** 开始，而不是直接打开工作台：这样先说明“为什么要刷这道题”，再说明“Agent 怎样完成复盘”，最后用评测证明“如何验证”。

## 推荐阅读顺序

1. `01_项目定位与架构.md`：产品边界和三入口结构。
2. `02_Agent技术详解.md`：Runtime、Tool、Recovery、Memory 与 Replay。
3. `03_评测体系与真实结果.md`：真实数字、实验条件和不能外推的边界。
4. `04_三分钟演示脚本.md`：现场按时间走完整业务闭环。
5. `05_面试追问与回答.md`：准备技术深挖。
6. `简历项目经历-Agent应用版.md` 或 `简历项目经历-大模型算法版.md`：按岗位直接使用。

## 口径边界（必须区分）

- **Agent 100%**：是固定确定性回归的任务/检索/恢复/重放/安全通过率；主演示为规则 Runtime，`model_calls=0`，不能描述为模型准确率。
- **模型实验**：冻结测试集只有 3 张公开教学图像。可以说“在该冻结小样本上观察到”，不能说泛化能力、临床能力或医学有效性。
- **学习状态**：UI 发起作答时传 `commit_memory=true`，结果写到 `backend/runtime/data/portfolio_study_state.json`；`/api/demo/reset` 可清理。离线回归与 Replay 不写入，以免污染结果与进度。
