# 从这里开始：作品集阅读地图

本目录面向两类读者：第一次接手项目的本人，以及会深入追问实现细节的技术面试官。

## 一句话定位

**内镜智训 Agent** 是一个面向消化内镜研修的多模态教学 Demo：医生围绕公开内镜图像作答或圈画，受控 Agent 调用证据检索、事实评分和安全核验工具，返回可追踪反馈、画像 Delta 与下一任务建议。

项目不提供自主临床诊断，所有医学输出均为教学或医生复核前辅助。

## 推荐阅读顺序

1. `01_项目定位与架构.md`：先理解为什么重构、主链是什么。
2. `02_Agent技术详解.md`：看 Agent Runtime、工具、Trace、记忆和降级。
3. `03_评测体系与真实结果.md`：看哪些数字是真的、测试条件是什么。
4. `04_三分钟演示脚本.md`：现场演示按这里走。
5. `05_面试追问与回答.md`：准备技术面试深挖。
6. `项目简历介绍建议-Agent应用.md` 或 `项目简历介绍建议-大模型算法.md`：按岗位选择简历表述。

## 可验证入口

```powershell
cd code
$env:PYTHONPATH="backend"
python -m unittest discover -s backend/tests -v
python -m app.services.portfolio_eval_service

cd frontend
npm run build
```

关键产物：

- Agent 回归结果：`artifacts/eval/latest.json`、`latest.md`
- 模型实验结果：`artifacts/model_eval/`（只有真实运行成功后才出现）
- 版本基线：Git tag `portfolio-v1.0`
- 重构版本：Git branch `feat/portfolio-agent-v2`
