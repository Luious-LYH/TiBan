**问题描述**：

- `memory_service.py` 只记录错题，没有计算下次复习时间

**面试风险**：
- 面试官问："你的复习算法是怎么实现的？"
  - ❌ 无法回答，代码中不存在

**解决方案**：
```python
# 实现简化版 SM-2 或 FSRS-4.5
def calculate_next_review(
    quality: int,  # 0-5，用户自评
    interval: int,  # 当前间隔（天）
    easiness: float,  # 容易度因子
    repetitions: int,  # 重复次数
) -> tuple[int, float, int]:
    """返回 (下次间隔, 新容易度, 新重复次数)"""
    if quality < 3:
        # 答错，重新开始
        return (1, easiness, 0)
    
    new_easiness = max(1.3, easiness + 0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
    
    if repetitions == 0:
        next_interval = 1
    elif repetitions == 1:
        next_interval = 6
    else:
        next_interval = round(interval * new_easiness)
    
    return (next_interval, new_easiness, repetitions + 1)
```

### 3. RAG 和向量检索缺失 ❌

**问题描述**：
- 简历声称"BM25-equivalent RAG"，实际只有简单的文本匹配
- 没有向量数据库（ChromaDB/FAISS/Pinecone）
- 没有 embedding 模型
- 没有混合检索（稀疏 + 稠密）

**面试风险**：
- 面试官问："你的 RAG 怎么做 embedding？用的哪个模型？"
  - ❌ 无法回答
- 面试官问："混合检索的权重怎么调的？"
  - ❌ 没有实现

**解决方案**：
```python
# 1. 添加向量存储
from chromadb import Client
from sentence_transformers import SentenceTransformer

class KnowledgeRAG:
    def __init__(self):
        self.client = Client()
        self.collection = self.client.create_collection("medical_knowledge")
        self.encoder = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
    
    def add_documents(self, docs: list[dict]):
        """添加文档到向量库"""
        texts = [doc['content'] for doc in docs]
        embeddings = self.encoder.encode(texts).tolist()
        ids = [doc['id'] for doc in docs]
        self.collection.add(embeddings=embeddings, documents=texts, ids=ids)
    
    def hybrid_search(self, query: str, top_k: int = 3) -> list[dict]:
        """混合检索：BM25 + 向量相似度"""
        # 稠密检索
        query_embedding = self.encoder.encode([query])[0].tolist()
        dense_results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=top_k
        )
        
        # BM25 稀疏检索（已有实现）
        sparse_results = self._bm25_search(query, top_k)
        
        # 加权融合 (0.3 * BM25 + 0.7 * Dense)
        return self._merge_results(sparse_results, dense_results, alpha=0.3)
```

### 8. SSE 流式输出缺失 ❌

**问题描述**：
- 简历声称"SSE 流式事件"
- 前端 ChatAgent 使用轮询，不是 SSE
- 后端没有 `@router.get("/agent/stream")` 接口

**面试风险**：
- 面试官问："打开开发者工具看看你的 SSE 连接"
  - ❌ 没有 SSE，是普通 HTTP 请求

**解决方案**：
```python
from fastapi.responses import StreamingResponse

@router.post("/agent/stream")
async def agent_stream(request: AgentRequest):
    """SSE 流式返回 Agent 执行过程"""
    async def event_generator():
        yield f"event: start\ndata: {json.dumps({'run_id': run_id})}\n\n"
        
        # Plan 阶段
        yield f"event: phase\ndata: {json.dumps({'phase': 'Plan', 'status': 'running'})}\n\n"
        # ... 执行 Plan 逻辑
        yield f"event: phase\ndata: {json.dumps({'phase': 'Plan', 'status': 'completed'})}\n\n"
        
        # Act 阶段
        yield f"event: phase\ndata: {json.dumps({'phase': 'Act', 'status': 'running'})}\n\n"
        # ... 执行 Act 逻辑
        
        yield f"event: done\ndata: {json.dumps({'result': result})}\n\n"
    
    return StreamingResponse(event_generator(), media_type="text/event-stream")
```
