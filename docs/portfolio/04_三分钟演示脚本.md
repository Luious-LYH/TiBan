# 三分钟演示脚本

## 0:00–0:20 首页

“这是一个面向消化内镜研修的多模态 Agent Demo。主线不是模型聊天，而是围绕一张公开病例完成可追踪的教学任务。”

点击“开始演示病例”。

## 0:20–0:55 独立观察

- 说明病例教学目标和公开题源。
- 在图像上圈画可疑区域。
- 提交一条不完整或包含常见错误的作答。

## 0:55–1:35 Agent 执行收据

展开 run ID 和五阶段 Trace：

- Plan：目标、工具顺序、医疗约束。
- Act：3 个 typed tools。
- Observe：命中证据 ID。
- Verify：结构和安全检查。
- Memory：画像 Delta 预览。

强调 Provider/Rule/Fallback 标签不会混用。

## 1:35–2:15 事实级复盘

- 展示 Fact P/R/F1，而不是字符串完全匹配。
- 解释命中事实、遗漏事实和错因标签。
- 展示推荐下一题的理由。

## 2:15–2:40 同病例报告交接

进入报告辅助，说明证据台账、无依据声明审查和医生复核闸门。

## 2:40–3:00 技术证据

打开模型实验室或展示 `artifacts/eval/latest.md`：

- Agent 编排回归与模型推理实验分开。
- 每个简历数字都能回到 JSON Artifact 和复现命令。
