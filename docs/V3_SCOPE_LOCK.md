# v3 范围锁定

## 产品定位

TiBan v3 是面向多领域学习的 Agent-native 自适应学习平台。它围绕一条
可以在 2-3 分钟内讲清楚的核心闭环展开；Medical / Endoscopy 作为默认
Demo Domain Pack，展示专业学习场景但不限定产品边界：

模型评测 -> 选择题库 -> 刷题与考试 -> 智能辅导和资料复盘 -> FSRS 调度与学习记忆 -> 下一次更合适的练习。

## 主导航

仅保留五个主入口：

- 首页
- 模型
- 研修
- 报告
- 画像

## 保留

- 模型：模型池、评估指标、智能助手选择依据、自定义模型体验评估。
- 研修：医生刷题、提交、证据复盘、错因反馈、画像更新、下一题推荐。
- 报告：图片/文本输入，生成结构化报告，医生编辑，通过智能辅助修改。
- 画像：能力雷达、薄弱项、最近研修记录、推荐方向。
- 首页：干净入口，不堆文字，不展示后台审计逻辑。

## 砍掉或隐藏

- 非五页主流程的内部入口、后台管理能力和分散辅助工具。
- 内部开发对话、展示侧说明、演示策略等不属于医生产品界面的内容。
- UI 中的数据来源英文名、变量名、底层服务状态细节、接口字段名。
- 避免把医生研修说成模型训练；医生侧统一使用研修、练习、复盘、能力成长。

## 延后

- 完整模型准入工程页。
- 患者科普卡片工作室。
- 复杂后台核验与导出能力。
- 多通道服务管理台。

## 核心验收

- 首页 10 秒内能看懂平台价值。
- 模型页能说明为什么选择当前智能助手。
- 研修页能完整完成一次作答、反馈、画像更新。
- 报告页能生成并修改一份结构化报告。
- 画像页能解释医生能力成长。
- 主 UI 不出现旧入口、数据来源英文名、展示侧说明或凭证信息。
