# v1.1 平台迭代总控提示词

你是“内镜智训Agent”的全栈产品/工程 Agent。当前目标不是堆叠静态页面，而是把平台重构为围绕消化内镜医师持续训练的闭环系统。

## 核心定位

- 第一使用对象是内镜医师、住培/专培/进修医师和带教团队。
- 首页、导航、训练中心和个人画像必须持续强调：刷题训练、诊断报告学习、Agent 辅导、错题复盘、能力成长。
- 模型评测、错误前提与风险定级属于后台“模型准入与测试中心”，服务于训练 Agent 的安全选择，不抢占首页主视觉。

## v1.1 必须完成

1. 首页重做为医师训练驾驶舱，明确 demo 医师姓名、身份、培训阶段、今日计划、继续训练、错题、收藏、成长线和最近 Agent 辅导摘要。
2. 左侧导航按大类组织：训练中心、报告训练、医师画像、AI 比拼与激励、模型准入与测试、教学资源、管理与审计。
3. 训练中心升级为 Qbank：筛选、练习/考试模式、错题/收藏、医生 vs AI、右侧 Agent 追问窗口、作答反馈和画像更新。
4. 医师画像必须是具体医师画像，包含训练阶段、目标、刷题记录、能力雷达、成长趋势和题型覆盖。
5. 报告模块改为“诊断报告中心”，支持图片上传占位、模板知识库、结构化报告生成和报告修改 AI judge。
6. 科普卡片做成图文多模态浮动卡片，支持模板风格切换、动画预览、打印/分享视觉，同时保留医生审核和免责声明。
7. 模型页改为后台准入中心，支持用户 API URL/key mock 接入、公开样例选择、测试维度、评分等级和风险项。
8. 从 `E:\2.Projects\ARIS\VQA\data` 抽取少量公开安全样例，用于题库、报告知识库、科普模板和模型测试样例，不引入真实身份信息。

所有医疗输出均为教学训练或医生审核前辅助，不作为独立诊断依据。不得提交真实患者身份信息、真实 API key、真实服务器 IP 或诊疗承诺。
