# 模型算法证据包

## 一句话结论

在单张 RTX 4090 上对 Qwen2.5-VL-3B-Instruct 做了 7 张公开内镜教学图像的确定性基准：事实级准确率 **20.0%**、P50/P95 生成延迟 **0.871/1.646 秒**、生成速度 **19.81 tokens/s**、峰值显存 **10.20 GiB**。结果显示通用 3B VLM 延迟可用于交互 Demo，但专业事实识别仍有明显领域缺口。

随后完成 1 样例、1 step 的 NF4 QLoRA 工程链路验证：LoRA rank 8，训练参数 **1,843,200 / 3,756,466,176（0.0491%）**，峰值显存 **8.90 GiB**。该 smoke run 只证明训练链路可执行，**不声称模型效果提升**。

又以同 7 个训练样例执行了 10-step overfit sanity：固定训练样例 loss 从 **1.9071 降至 1.7230（下降 9.65%）**，峰值显存 **17.98 GiB**，保存的 LoRA adapter 为 **7.05 MiB**。这是数据→4bit 模型→LoRA→反向传播→adapter 持久化的闭环证据，仍不属于验证集效果。

## 简历可用表述

### 大模型算法岗

> 构建内镜 VLM 可复现评测链路，以 7 张 Kvasir-VQA-x1 / EndoBench 公开教学样例进行事实级拆分评分，在 RTX 4090 上测得 Qwen2.5-VL-3B 的 P50/P95 延迟 0.87/1.65s、19.81 tokens/s 和 10.20GiB 峰值显存；定位通用模型事实准确率仅 20.0% 的领域失配，并完成 NF4 + LoRA（r=8、仅 0.0491% 参数可训练）的 10-step 训练链路及 adapter 持久化，为后续领域数据构建和对照实验建立基线。

### Agent 应用岗加分项

> 将模型评测从前端硬编码分数改为只读实验 Artifact，统一输出模型、精度、样例范围、事实准确率、P50/P95、吞吐和显存，并保留逐例回答与原始日志，使 Agent 模型选择可追溯、可回归。

## 面试边界

- 可以说：完成真实推理基准、发现领域缺口、完成 QLoRA 训练链路和 adapter 持久化验证。
- 不可说：微调后准确率提升、临床有效、20% 是统计泛化结论。
- 数据规模只有 7 张；它适合 Demo 与工程回归，不适合论文级模型比较。

## 下一步最值钱的实验

固定训练/验证拆分，构建 100–300 条部位、病灶、数量和阴性发现的结构化指令数据；比较 base / prompt+evidence / QLoRA 三组的事实 F1，并在同一硬件、同一生成配置下报告效果—显存—延迟 Pareto。只有得到独立验证集提升后，才把“微调提升”写进简历。
